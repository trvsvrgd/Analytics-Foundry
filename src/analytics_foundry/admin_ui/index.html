Getting Started with Analytics Foundry

Welcome to your ETL Workbench! Follow these steps to ingest, transform, and profile your NFL data:

1

Sync Broad NFL Data

Click Sync broad NFL in the Batch Ingest card to load the master players database. This is required for player mappings and injury calculations.

2

Sync League Metadata

Enter a Sleeper League ID (e.g. 1261894762944802816) and click Sync to fetch league rosters, matches, and configurations.

3

Explore and Analyze

Head to the Tables tab to browse medallion schemas and lineage, or use the Models tab to build low-code dataset projections.

Model Workspace

Build custom datasets without writing SQL by stacking filter, select, rename, join, and union operations. Click Save Model, then run materialization to write outputs to local storage.

How to Build Low-Code Models

Models transform your raw Bronze tables into curated datasets using simple logical operations:

1

Define Target

Give your model a name and select a starting source dataset (e.g. bronze:nfl_sleeper.players).

2

Add Operations

Choose an operation (like Filter, Choose columns, or Group), specify settings, and click Add operation. You can stack multiple operations.

3

Save & Materialize

Click Save model. Once saved, click Preview to inspect rows in-memory, or Materialize to save the outputs to local disk.

Data Quality & Assertions

Configure automated data quality checks (required columns, acceptable values, numeric ranges, and referential checks) to monitor data integrity and log failing rows.

How to Configure Quality Rules

Attach assertions to tables to monitor freshness, completeness, and values:

1

Select Dataset

Choose a target table from the dropdown. The builder will automatically read the schema and suggest rules for each column.

2

Create Assertion

Select a Rule type (e.g. Required, Accepted values, Numeric range) and fill out the parameters. Click Save rule.

3

Run & Alert

Click Run checks to execute rules. Any failures will log detailed record samples and trigger configured Slack/Webhook alerts.
